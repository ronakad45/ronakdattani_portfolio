Next-day air quality prediction for five Middle Eastern cities

A full-stack machine learning web app with a live dashboard, 5-day forecasts, city comparison, historical trend charts and a quiz-based leaderboard. It is mobile responsive and publicly accessible with no login.

I scoped the feature set around what end users needed, built every layer myself, and ran user acceptance testing before release.
